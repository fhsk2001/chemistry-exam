# 🧪 Изпит по Химия - Уеб приложение за 8 клас

Интерактивно уеб приложение за изучаване и тестване на химия на елементарно ниво, предназначено за ученици от 8 клас.

## 🎯 Функционалности

### 📊 Периодична таблица
- Интерактивна визуализация на 14 основни елемента
- Цветни карти с химични символи
- Подробна информация за всеки елемент:
  - Химичен символ
  - Название
  - Атомно число
  - Атомна маса

### 📝 Тест по Химия
- 10 въпроса за проверка на знаниях
- Мултипълни избор с 4 варианта
- Моментална обратна връзка
- Обяснение за всеки отговор
- Резултат в процент и оценка

### 📈 Анимирани Графики
- График на атомните номера (Bar Chart)
- График на атомните маси (Line Chart)
- Интерактивни визуализации с Chart.js

### ℹ️ Информационна Страница
- Ръководство за използване
- Статистика на приложението

## 🚀 Инсталация и Стартиране

### Локално Тестване

```bash
# 1. Клониране на репозиторията
git clone https://github.com/fhsk2001/chemistry-exam.git
cd chemistry-exam

# 2. Инсталиране на Python зависимостите
pip install -r requirements.txt

# 3. Стартиране на Flask сервъра
python app.py

# 4. Отваряне в браузър
# Отиди на http://localhost:5000
```

## 🎓 За Учениците

**Как да използваш приложението:**

1. **Начало:** Посети периодичната таблица, за да запознаеш се с елементите
2. **Учене:** Кликни на всеки елемент, за да видиш деталлите му
3. **Практика:** Отговори на въпроси в секцията "Тест"
4. **Анализ:** Гледай графиките, за да разбереш връзката между атомните номера и маси

## 📊 API Endpoints

```
GET  /api/elements              # Всички елементи
GET  /api/quiz                  # 5 произволни въпроса
POST /api/check-answer          # Проверка на отговор
GET  /api/get-element?symbol=H  # Детайли на елемент
```

## ❓ FAQ

**Как да добавя нови въпроси?**
Отваря файла `app.py` и редактирай списъка `QUESTIONS`.

**Как да добавя нови елементи?**
Отваря файла `app.py` и редактирай словаря `ELEMENTS`.

**Мога ли да го хостнам безплатно?**
Да! Можеш да използваш Replit, PythonAnywhere, или Heroku (безплатни нива са налични).
